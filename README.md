## 📌 Sobre o Projeto
O **Treino Chad** foi desenvolvido para me ajuda a organizar minha rotina de musculação, visualizar minhas metas e acompanhar o meu progresso de forma simples e motivadora.

## ✨ Funcionalidades
- [x] **Gerenciamento de Treinos:** Seleção de rotinas por grupos musculares.
- [x] **Contabilização de Macros e Água:** Calculo de calorias ingeridas diariamente.
- [x] **Histórico e Progresso:** Registro de treinos concluídos e sistema de conquistas.
- [x] **Interface Responsiva:** Design otimizado tanto para dispositivos móveis quanto para desktop.

## 🛠️ Tecnologias Utilizadas
- **HTML5** — Estrutura semântica da aplicação.
- **CSS3** — Estilização personalizada, layout responsivo e elementos visuais avançados.
- **JavaScript** — Manipulação do DOM e persistência dos dados de progresso.
